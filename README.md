# Ahmed Cars

A lightweight 3D-style browser racing game built entirely in HTML, CSS, and JavaScript with no external dependencies.

## How to run

Open `index.html` in a browser.

## Controls

- Up Arrow: accelerate
- Down Arrow: brake
- Left/Right Arrow: steer

## Objective

Race around the track, avoid traffic, and complete 3 laps to finish the championship.

## Project name

`Ahmed Cars`
